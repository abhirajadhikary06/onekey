Onekey

SDK Documentation

Quick Start

Install the Onekey SDK and CLI to manage all your API keys with a single platform key.

# Install via pip
pip install onekey

Initialize your client in Python:

from onekey import OnekeyClient

# Automatically picks up ONEKEY_PLATFORM_API_KEY from .env
client = OnekeyClient()

LLM Integrations

Power 20+ LLM providers with a single unified interface.

# Chat with any model (OpenAI, Anthropic, Groq, etc.)
response = client.llm.chat(
    provider="groq",
    model="llama3-70b-8192",
    messages=[{"role": "user", "content": "Hello!"}]
)
Region Providers
Standard OpenAI, Claude, Groq, Gemini
Advanced Mistral, OpenRouter, DeepSeek, Together
Specialized Perplexity, AI21, Cohere, Replicate

Infrastructure & DevOps

Full control over your cloud resources via Onekey Proxy.

DevOps (GitHub, Vercel, Render)

# GitHub Operations
repos = client.devops.list_repos("github")

# Vercel Operations
projects = client.devops.list_projects("vercel")

# Render Operations
services = client.devops.list_services("render")

Databases (Vector & Cloud)

# Vector Database
indexes = client.vector_db.list_indexes("pinecone")

# Cloud Database
db_projects = client.database.list_projects("neondb")

General Purpose APIs

Access popular SaaS APIs using a single platform key.

# Universal API Passthrough
response = client.apis.call(
    provider="stripe",
    operation="list_customers"
)

# Supported: Stripe, Twilio, SendGrid, Slack, Notion, Shopify, Discord

Direct API Proxy

Use any language or tool (curl, Postman) to call the proxy via REST.

# Generic request format
POST /proxy/sdk/{category}/{provider}
Authorization: Bearer <YOUR_PLATFORM_KEY>
Content-Type: application/json

{
  "operation": "list_repos",
  "params": {}
}
